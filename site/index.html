Tessera

A modular operating system for CC: Tweaked computers. Small core, everything else on demand.

Install

On a computer with HTTP enabled, run:

wget run https://OWNER.github.io/REPO/install.lua

The installer sets up the core and the package manager, then offers the setup wizard, which detects your hardware and recommends modules.

No HTTP on your server?

Pastebin backup: the installer is also published as a paste (see the project README for the id): pastebin run <id>

Completely offline: download install.lua and a bundle below. Drag install.lua onto the game window (or copy it in with a disk) and run it. When it asks for data, drag the .tsrbundle file onto the window — or paste the numbered TSR1 lines one at a time. Everything is checksummed; a bad line is rejected and can simply be pasted again.

full.tsrbundle (drag-and-drop) · full.txt (paste lines)

Packages

After installing: pkg search, pkg install <name>. The registry is a plain static site: registry/index.json.
