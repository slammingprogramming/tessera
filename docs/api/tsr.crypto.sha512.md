# tsr.crypto.sha512

Package: `crypto`

SHA-512 (FIPS 180-4) in pure Lua on bit32, with 64-bit words kept as (high, low) pairs of 32-bit numbers.
The constants were generated by tools/dev/sha512-constants.mjs with exact integer arithmetic.

## `M.digest(msg)`

SHA-512 of `msg` as a 64-byte binary string. Long inputs yield to the scheduler now and then.

## `M.hex(msg)`

SHA-512 as 128 lowercase hex characters.
